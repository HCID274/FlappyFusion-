# 游戏设计文档(GDD) — 核聚变 Flappy 科普小游戏

> 本文档定义"游戏是什么、玩起来什么感觉、数值是多少"。
> 配套文档:`architecture.md`(代码怎么组织) / `content.md`(玩家看到的文字)。
> **§11 的初始数值是 `config.js` 的权威来源**。任何调参先改 GDD,再同步到 config。

---

## 1. 设计目标

### 1.1 玩家是谁
开放日参观者:小学生、家长、高中/大学生、偶尔有同行学者。**没有游戏背景的人占多数**。展位停留时间 1–3 分钟。

### 1.2 一次完整体验里玩家应该带走的三件东西
1. **身体记忆**:"维持等离子体悬浮真的很难,我一不留神就撞墙了"
2. **一个具体的数字**:1 亿度 = 聚变点火温度;ITER 目标是 400 秒
3. **一个反差**:1g 燃料 = 8 吨石油的能量密度对比

游戏的所有设计都要反过来服务这三件事。任何加进来的元素如果不服务这三件事之一,要默认砍掉。

### 1.3 设计取舍
| 当冲突时 | 优先 | 牺牲 |
|---|---|---|
| 上手门槛 vs 操作深度 | 上手门槛 | 高玩深度 |
| 科普准确 vs 玩感 | 玩感 | 学术严格(可在死亡卡片"了解更多"补) |
| 视听冲击 vs 性能 | 性能(60 FPS 是底线) | 粒子数量 |
| 重玩动机 vs 单局完整 | 单局完整 | 长期养成 |

```
进入展位 ──► 看到大屏 ──► 按空格 ──► 教程一句话 ──► 开始游戏
                                                          │
                                                          ▼
                              ┌───────  3 秒就懂玩法  ◄────┐
                              │                            │
                              ▼                            │
                          躲偏滤器                          │
                          吃 D/T                           │
                          看温度爬升 ─── 飘字科普 ─────────┘
                              │
                              ▼
                          撞墙 / 撞障碍

                              │
                              ▼
                  [再来一次] ──► 回到开始
```

## 3. 操作

| 输入 | 行为 | 反馈 |
|---|---|---|
| 空格(按下) | 触发一次磁场脉冲,等离子体获得向上速度 | HUD 顶部"磁场强度环"亮一下;光球短暂高亮;轻微"嗡"音(可选) |
| 空格(在 Menu) | 开始游戏 | 教程画面淡出 |
| 空格(在 Dead) | 重开 | 死亡卡片淡出 |

**没有其他按键**。鼠标只用于点击死亡卡片上的"了解更多"按钮(展位无鼠标也能纯键盘游玩,但需鼠标看二维码相关内容)。

## 4. 等离子体的物理感受

这是整个游戏"手感"的核心,数值都为这个手感服务。

### 4.1 漂移(Drift)
等离子体不是"自由落体",而是"持续下沉"——**像热气球泄气**。视觉上有轻微 wobble(横向微振),营造"活的等离子体"感觉。

物理原理可在死亡卡片上写一句:"现实中等离子体在磁场里因 ∇B 漂移和曲率漂移会自然偏离平衡位置"。

### 4.2 脉冲(Pulse)
按一次空格 = 一次"反向磁场脉冲",光球获得**向上的速度增量**,而不是位置突变。这点和 Flappy 一致,但视觉反馈更柔和:

- 光球顶部短暂出现一道青色磁力线波纹
- 拖尾向下喷出一小段(像火箭尾焰但是磁约束语境)

### 4.3 拖尾
保留过去 8–12 帧的位置,画成渐隐的粒子轨迹,洋红→紫→透明。这让光球显得有动量,不是干瘪的圆。

### 4.4 边缘警告
当光球距离上下炉壁 < 30 px 时,炉壁对应区域**红色脉动**,提示危险。这个反馈很重要,是新手最需要的安全感来源。

## 5. 场景元素(障碍 / 软障碍 / 加成)

> 场景里所有"会从右向左滚过"的非收集物对象,无论是阻挡、惩罚还是奖励,都归在这一节。
> 收集物(D / T / ⁶Li)在 §6。

### 5.1 偏滤器(Divertor)— 主线障碍(致死)
**视觉**:从上下炉壁伸入腔室的金属构件,带散热鳍片纹理。一对(上 + 下),中间留空隙。
**碰撞**:两个独立 AABB hitbox。
**生成节奏**:每次生成的 spacing(障碍中心间距)在 [spacingMin, spacingMax] 随机。
**间隙宽度**:gap 在 [gapMin, gapMax] 随机,**间隙垂直位置随机**(但与上一个障碍的间隙位置相比偏移不超过 120 px,避免连续大跳)。
**通过判定**:当障碍 x < plasma.x 时标记 passed,触发 +1 分和 +0.2 温度进度。

### 5.2 MHD 不稳定区(InstabilityRegion)— 特殊障碍(致死)
**视觉**:一团扭曲的红色等离子体云,带湍流动画(用低频 Perlin 或简单正弦扰动)。
**出现概率**:每次生成时,15% 概率生成 InstabilityRegion 替代当次 Divertor。**不能连续两次**生成不稳定区。
**形状**:不是规则矩形,而是 2–3 个椭圆 hitbox 拼成,中间留出可穿过的窄通道。
**飘字**:生成时屏幕中部短暂浮现障碍名称("撕裂模" / "气球模" / "锯齿模" 三选一),0.8 秒后淡出。

### 5.3 钨碎片(TungstenDebris)— 软障碍(不致死,温度倒退)
**视觉**:破碎金属碎片簇,工业冷灰色,锐利棱角(贴图见 `docs/assets.md` `hazard_tungsten.png`)。
**碰撞**:1 个 AABB hitbox(80×80)。撞到后:
- **不死**,等离子体继续飞行
- 温度倒退 1 档(`world.temperature -= CONFIG.temperature.increment`,不低于 start)
- 屏幕红闪 0.3 秒,等离子体短暂闪烁
- 飘字 `钨杂质溅射 — 等离子体冷却`(见 `content.md` §6.3)
- 该钨碎片立即标记 triggered,不再重复触发
**生成**:**独立于偏滤器主线,作为额外滚动元素**。每 spawn 周期 8% 概率插入一个,y 在 [80, height-80] 随机。不计入 obstaclesPassed,不加分。
**为什么不直接致死**:致死障碍已经有偏滤器和不稳定区两种,再多一种会让玩家"啥都不敢做"。软障碍引入"代价型"决策:遇到时是闪还是硬吃 — 给玩家有意义的选择。
**科普点**:聚变堆第一壁的 W(钨)壁材在等离子体溅射下会落入芯部,作为高 Z 杂质会通过辐射快速冷却等离子体 — 现实里就是这样"杀温度"的。

### 5.4 NBI 中性束(NeutralBeamInjection)— 加成通道(温度奖励)
**视觉**:横向洋红粒子流带,两端羽化(贴图见 `docs/assets.md` `boost_nbi.png`,240×72)。
**判定**:1 个 AABB hitbox。等离子体接触后:
- 立即温度 +1 档(`world.temperature += CONFIG.temperature.increment`,可触发 TEMP_MILESTONE)
- 等离子体 0.5 秒金光高亮
- 飘字 `中性束加热!+1 档`(见 `content.md` §6.4)
- 该 NBI 立即标记 triggered + 视觉淡出,不能反复刷
**生成**:**独立额外滚动元素**。每 spawn 周期 5% 概率插入一个,y 在 [120, height-120] 随机(避开炉壁警告区)。
**为什么放进游戏**:正反馈 + 引入"想去够"的目标,鼓励玩家做大动作机动而不是平淡飞行。
**科普点**:NBI(中性束注入加热)是托卡马克主流加热手段之一,把高能中性原子打进等离子体,通过碰撞把能量传给离子。

### 5.5 场景元素生命周期
```
spawn at x = canvas.width + 100
       ↓ scrollSpeed × dt
through screen
       ↓
when x < -150 → cleanup
```

致死障碍(divertor / instability)、软障碍(tungsten)、加成(nbi)共用同一套生命周期与滚动逻辑;
区别只在生成概率(主线 / 额外)和碰撞触发的事件类型。

## 6. 收集物与聚变系统

### 6.1 氘原子(D)与氚原子(T)
**视觉**:D 蓝色发光小球(直径 16 px),内部画 1 个白点;T 绿色发光小球,内部画 2 个白点。区分度要高,色弱也能分辨(蓝 vs 绿 + 形状差异)。
**生成**:每对 Divertor 之间的间隙中,**70% 概率**飘 1 个原子,D/T 各 50% 概率。
**位置**:在间隙中心 ±40 px 随机偏移。
**碰撞**:吃到 +1 分,光球 +0.5 圈短暂高亮,记录到 `world.collectedD/T`。

### 6.2 锂-6 原子(⁶Li)— 增殖物(稀有)
**视觉**:紫银色发光原子,**辉光明显比 D/T 强**,中央叠白色 `⁶Li` 标签(贴图见 `docs/assets.md` `atom_li6.png`,96×96)。
**生成**:与 D/T 共用收集物 spawn 通道,但权重很低(10%,见 §11 `collectible.typeWeights`)。位置同 D/T。
**碰撞**:吃到立即:
- `world.collectedT += 1`(若 T 槽未满,直接增殖出 1 个 T;槽满则吃到也 +2 分但不入库)
- +2 分(比 D/T 多一倍,体现稀有)
- 飘字 `⁶Li → T 增殖`(见 `content.md` §6.2)
**设计意图**:
- **机制变化**:给 T 第二条来路,玩家追稀有物时有"赚到了"的爽感
- **科普点**:聚变堆靠 ⁶Li + n → T + ⁴He 的反应在包层(blanket)里增殖 T,因为 T 半衰期 12.3 年、自然界几乎没有,聚变堆必须自己造 — 这是工程聚变里玩家最容易忽视但最关键的物理之一

### 6.3 聚变事件
当 `collectedD ≥ 1 && collectedT ≥ 1` 时:
1. 立即触发聚变特效:
   - 光球瞬间放大 1.3×,白色闪光 0.1 秒
   - 飞出 1 个红色 He4 粒子(向左下飘) + 1 个白色中性子粒子(向右上飘),自带文字标签 "He⁴" / "n"
   - +5 分,屏幕得分数字短暂金色高亮
2. 扣除 1D + 1T(`collectedD -= 1; collectedT -= 1`)
3. `world.fusionCount += 1`

**设计目的**:让玩家意识到"我刚刚做了一次聚变反应",而不只是收集数字。HUD 应该用**视觉化燃料舱**实时显示 D / T 库存与聚变就绪状态(详见 §10.2)。

### 6.4 燃料舱库存上限
- D / T 各有上限(`config.fusion.fuelBaySlots = { D: 3, T: 3 }`),与左上角 HUD 槽位 1:1 对应
- **超过上限的 D/T 拾取仍 +1 分**(避免浪费惩罚 / 手感惩罚),但 `collectedD/T` 不再上涨
- 上限的存在让"长时间不聚变"也不会无脑积压库存,鼓励即时消耗

### 6.5 H 模光环(可选,二期再做)
**视觉**:金色环形,缓慢旋转。
**出现概率**:每 5% 障碍间隙生成一个,且距离上一个 ≥ 20 个障碍。
**效果**:吃到后 3 秒无敌(可穿过障碍),屏幕轻微金色调,飘字 "H-Mode 高约束模"。

> 如果几天开发时间紧,**先砍掉 H 模光环**,只做 D/T 聚变。

## 7. 难度曲线

### 7.1 温度爬升
| 通过障碍数 | 温度(百万度) | 折算 |
|---|---|---|
| 0 | 10 | 1000 万度(起步) |
| 4 | 20 | 2000 万度 |
| 16 | 50 | **5000 万度 — 太阳核心** |
| 28 | 80 | **8000 万度 — 劳森判据下限** |
| 36 | 100 | **1 亿度 — 聚变点火温度!** |
| 56 | 150 | **1.5 亿度 — 超越 ITER** |
| 76 | 200 | **2 亿度 — 突破现役纪录** |

公式:`温度(M°) = 10 + floor(obstaclesPassed / 4) × 10`

**注意**:NBI 加成通道也会推进温度档(见 §5.4),钨碎片会倒退温度档(见 §5.3)。这两个不计入 obstaclesPassed,但会让实际温度偏离上表 ±1~3 档,这是有意的张力来源。

### 7.2 滚速联动
`scrollSpeed = baseSpeed + (温度档位) × speedPerStep`

| 障碍数 | 温度档位 | 滚速 |
|---|---|---|
| 0 | 0 | 110 px/s |
| 20 | 5 | 150 px/s |
| 40 | 10 | 190 px/s |
| 80 | 20 | 270 px/s |

起步约每 3 秒过一个障碍,点火(100M°)时约 2 秒/障碍。

**为什么是这个速度(三轮校准的最终值)**:
- v0 原型(0.5s 安全窗) → 完全不可玩
- 第一轮 → drift=200 / baseSpeed=160(1.7s 安全窗,仍偏快)
- 第二轮 → 全部 ×1/3:drift=70 / baseSpeed=55(用户实测**过慢**,缺少节奏感)
- **第三轮(当前)** → 在第二轮基础上 ×2,即 v0 的 2/3:drift=140 / baseSpeed=110

目标:从画面中心到撞墙约 **2 秒**的安全窗口,飞行节奏约 **1.4 秒**一个完整起落,起步约 **3 秒**一个障碍。配合 `stepEveryNObstacles=4`,典型 60 秒一局能看到太阳核心,90 秒能摸到劳森到点火之间。

### 7.3 间距与间隙不变
障碍间距和垂直间隙保持随机区间不变。**难度提升只通过滚速来体现**——这样代码逻辑简单,玩家也容易感知"快了"。

## 8. 得分系统

| 来源 | 分值 |
|---|---|
| 通过 1 个障碍 | +1 |
| 吃到 1 个 D 或 T | +1 |
| 完成 1 次聚变(消耗 1D + 1T) | +5 |

**典型分数预期**:
- 30 秒内死亡:~25 分(20 障碍 + 几次吃原子,可能 0–1 次聚变)
- 60 秒生存:~70 分(40 障碍 + 多次聚变)
- 90 秒以上:~120 分

得分主要用于"我比刚才更厉害了"的局间对比,**不强调排行榜**(展位不适合)。

## 10. HUD 与界面元素

固定显示在画布四角的 DOM overlay。**HUD 不每帧重绘,只在事件发生时改 DOM**(订阅 EventBus)。

### 10.1 总览

| 位置 | 元素 | 何时更新 |
|---|---|---|
| 左上 | 温度计 + 燃料舱(见 §10.2) | TEMP_CHANGED / COLLECTIBLE_HIT / FUSION_TRIGGERED |
| 右上 | 得分 + 时间 | SCORE_CHANGED / 每帧 |
| 顶部中央 | 磁场强度环(空格时亮) | INPUT_PULSE |

### 10.2 燃料舱(Fuel Bay)— 聚变机制的核心可视化

**视觉化的库存,不是数字**。这是本作 HUD 的灵魂。

```
┌─ 燃料舱 ─────────────┐
│ 🌡 5000 万度          │   ← 温度计独立一行
├──────────────────────┤
│ D  ⬤  ◯  ◯           │   ← D 槽位 ×3:亮态/暗态视觉
│ T  ⬤  ◯  ◯           │   ← T 槽位 ×3:同上
├──────────────────────┤
│ ⚡ 聚变就绪 ⚡       │   ← collectedD≥1 ∧ collectedT≥1 时显示
│ He⁴ ×3                │   ← 已聚变次数(累计成就感)
└──────────────────────┘
```

**槽位状态切换**:
- **暗态**:CSS `filter: grayscale(1) opacity(0.3)`,只用一张亮版图,不需要美术做两版
- **亮态**:无 filter,加 `box-shadow` glow(色与 atom 主色一致),收集瞬间 1.5× → 1.0× 弹性弹动

**聚变就绪指示**:
- 当 `collectedD ≥ 1 && collectedT ≥ 1` 时,立即显示 `⚡ 聚变就绪 ⚡` 行
- 金色脉冲动画(scale 1.0 ↔ 1.1,0.6s 周期)直到聚变触发

**聚变触发瞬间**(订阅 `EV.FUSION_TRIGGERED`):
- 槽位执行炸开动画:`transform: scale(1.5) rotate(15deg); opacity: 0`,0.3 秒
- 0.3 秒后槽位重新渲染为新的 D/T 数(已扣减 1 + 1)
- He⁴ 计数 +1,数字弹跳(scale 1.0 → 1.4 → 1.0)

**槽位上限**:D 3 + T 3。超出上限的拾取仍 +1 分,但库存不增(避免节奏惩罚,见 §6.4)。

### 10.3 右上 — 得分与时间
| 字段 | 模板 | 何时更新 |
|---|---|---|
| 得分 | `★ {score}` | EV.SCORE_CHANGED |
| 时间 | `⏱ {seconds} s` | 每帧(由 hud.refresh(world) 驱动) |

### 10.4 顶部中央 — 磁场强度环
圆环,空格时短暂亮一下(0.15 秒)。订阅 `EV.INPUT_PULSE`。

### 10.5 不属于 HUD
- 飘字(温度里程碑、障碍名称、Li-6 增殖、NBI 加热、钨碎片冷却)由 ParticleSystem 在 Canvas 内绘制
- 死亡卡片是独立 DOM overlay(见 §12)

## 11. 平衡参数表(config.js 的权威来源)

```js
export const CONFIG = {
  canvas: { width: 800, height: 600 },

  plasma: {
    startX: 200,
    startY: 300,
    drift: 140,                // px/s²,下沉加速度。中心到底约 2s 安全窗口
    pulseImpulse: -150,        // 单次脉冲速度变化。飞行节奏 ~1.4s
    pulseCooldownTime: 0,      // 秒;先 0,平衡测试时再考虑
    radius: 14,
    trailLength: 10,
    wallWarningDistance: 30,
    maxFallSpeed: 230,
    maxRiseSpeed: -240,
  },

  obstacle: {
    gapMin: 200,
    gapMax: 240,
    spacingMin: 300,
    spacingMax: 360,
    gapJitterMax: 100,
```
