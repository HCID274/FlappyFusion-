# 游戏设计文档(GDD) — 核聚变 Flappy 科普小游戏

> 本文档定义"游戏是什么、玩起来什么感觉、数值是多少"。
> 配套文档:`architecture.md`(代码怎么组织) / `content.md`(玩家看到的文字)。
> **§11 的初始数值是 `config.js` 的权威来源**。任何调参先改 GDD,再同步到 config。

---

## 1. 设计目标

### 1.1 玩家是谁
开放日参观者:小学生、家长、高中/大学生、偶尔有同行学者。**没有游戏背景的人占多数**。展位停留时间 1–3 分钟。

### 1.2 一次完整体验里玩家应该带走的三件东西
1. **身体记忆**:"维持等离子体悬浮真的很难,我一不留神就撞墙了"
2. **一个具体的数字**:1 亿度 = 聚变点火温度;ITER 目标是 400 秒
3. **一个反差**:1g 燃料 = 8 吨石油的能量密度对比

游戏的所有设计都要反过来服务这三件事。任何加进来的元素如果不服务这三件事之一,要默认砍掉。

### 1.3 设计取舍
| 当冲突时 | 优先 | 牺牲 |
|---|---|---|
| 上手门槛 vs 操作深度 | 上手门槛 | 高玩深度 |
| 科普准确 vs 玩感 | 玩感 | 学术严格(可在死亡卡片"了解更多"补) |
| 视听冲击 vs 性能 | 性能(60 FPS 是底线) | 粒子数量 |
| 重玩动机 vs 单局完整 | 单局完整 | 长期养成 |

```
进入展位 ──► 看到大屏 ──► 按空格 ──► 教程一句话 ──► 开始游戏
                                                          │
                                                          ▼
                              ┌───────  3 秒就懂玩法  ◄────┐
                              │                            │
                              ▼                            │
                          躲偏滤器                          │
                          吃 D/T                           │
                          看温度爬升 ─── 飘字科普 ─────────┘
                              │
                              ▼
                          撞墙 / 撞障碍

                      死亡卡片(主科普位)
                              │
                              ▼
                  [再来一次] ──► 回到开始
```

## 3. 操作

| 输入 | 行为 | 反馈 |
|---|---|---|
| 空格(按下) | 触发一次磁场脉冲,等离子体获得向上速度 | HUD 顶部"磁场强度环"亮一下;光球短暂高亮;轻微"嗡"音(可选) |

| 空格(在 Dead) | 重开 | 死亡卡片淡出 |

## 4. 等离子体的物理感受

这是整个游戏"手感"的核心,数值都为这个手感服务。

### 4.1 漂移(Drift)
等离子体不是"自由落体",而是"持续下沉"——**像热气球泄气**。视觉上有轻微 wobble(横向微振),营造"活的等离子体"感觉。

物理原理可在死亡卡片上写一句:"现实中等离子体在磁场里因 ∇B 漂移和曲率漂移会自然偏离平衡位置"。

### 4.2 脉冲(Pulse)
按一次空格 = 一次"反向磁场脉冲",光球获得**向上的速度增量**,而不是位置突变。这点和 Flappy 一致,但视觉反馈更柔和:

- 光球顶部短暂出现一道青色磁力线波纹
- 拖尾向下喷出一小段(像火箭尾焰但是磁约束语境)

### 4.3 拖尾
保留过去 8–12 帧的位置,画成渐隐的粒子轨迹,洋红→紫→透明。这让光球显得有动量,不是干瘪的圆。

### 4.4 边缘警告
当光球距离上下炉壁 < 30 px 时,炉壁对应区域**红色脉动**,提示危险。这个反馈很重要,是新手最需要的安全感来源。

## 5. 场景元素(障碍 / 软障碍 / 加成)

> 场景里所有"会从右向左滚过"的非收集物对象,无论是阻挡、惩罚还是奖励,都归在这一节。
> 收集物(D / T / ⁶Li)在 §6。

### 5.1 偏滤器(Divertor)— 主线障碍(致死)
**视觉**:从上下炉壁伸入腔室的金属构件,带散热鳍片纹理。一对(上 + 下),中间留空隙。
**碰撞**:两个独立 AABB hitbox。
**生成节奏**:每次生成的 spacing(障碍中心间距)在 [spacingMin, spacingMax] 随机。
**间隙宽度**:gap 在 [gapMin, gapMax] 随机,**间隙垂直位置随机**(但与上一个障碍的间隙位置相比偏移不超过 120 px,避免连续大跳)。
**通过判定**:当障碍 x < plasma.x 时标记 passed,触发 +1 分和 +0.2 温度进度。

### 5.2 MHD 不稳定区(InstabilityRegion)— 特殊障碍(致死)
**视觉**:一团扭曲的红色等离子体云,带湍流动画(用低频 Perlin 或简单正弦扰动)。
**出现概率**:每次生成时,15% 概率生成 InstabilityRegion 替代当次 Divertor。**不能连续两次**生成不稳定区。
**形状**:不是规则矩形,而是 2–3 个椭圆 hitbox 拼成,中间留出可穿过的窄通道。
**飘字**:生成时屏幕中部短暂浮现障碍名称("撕裂模" / "气球模" / "锯齿模" 三选一),0.8 秒后淡出。

### 5.3 钨碎片(TungstenDebris)— 软障碍(不致死,温度倒退)
**视觉**:破碎金属碎片簇,工业冷灰色,锐利棱角(贴图见 `docs/assets.md` `hazard_tungsten.png`)。
**碰撞**:1 个 AABB hitbox(80×80)。撞到后:
- **不死**,等离子体继续飞行
- 温度倒退 1 档(`world.temperature -= CONFIG.temperature.increment`,不低于 start)
- 屏幕红闪 0.3 秒,等离子体短暂闪烁
- 飘字 `钨杂质溅射 — 等离子体冷却`(见 `content.md` §6.3)
- 该钨碎片立即标记 triggered,不再重复触发
**生成**:**独立于偏滤器主线,作为额外滚动元素**。每 spawn 周期 8% 概率插入一个,y 在 [80, height-80] 随机。不计入 obstaclesPassed,不加分。
**为什么不直接致死**:致死障碍已经有偏滤器和不稳定区两种,再多一种会让玩家"啥都不敢做"。软障碍引入"代价型"决策:遇到时是闪还是硬吃 — 给玩家有意义的选择。
**科普点**:聚变堆第一壁的 W(钨)壁材在等离子体溅射下会落入芯部,作为高 Z 杂质会通过辐射快速冷却等离子体 — 现实里就是这样"杀温度"的。

### 5.4 NBI 中性束(NeutralBeamInjection)— 加成通道(温度奖励)
**视觉**:横向洋红粒子流带,两端羽化(贴图见 `docs/assets.md` `boost_nbi.png`,240×72)。
**判定**:1 个 AABB hitbox。等离子体接触后:
- 立即温度 +1 档(`world.temperature += CONFIG.temperature.increment`,可触发 TEMP_MILESTONE)
- 等离子体 0.5 秒金光高亮
- 飘字 `中性束加热!+1 档`(见 `content.md` §6.4)
- 该 NBI 立即标记 triggered + 视觉淡出,不能反复刷
**生成**:**独立额外滚动元素**。每 spawn 周期 5% 概率插入一个,y 在 [120, height-120] 随机(避开炉壁警告区)。
**为什么放进游戏**:正反馈 + 引入"想去够"的目标,鼓励玩家做大动作机动而不是平淡飞行。
**科普点**:NBI(中性束注入加热)是托卡马克主流加热手段之一,把高能中性原子打进等离子体,通过碰撞把能量传给离子。

### 5.5 场景元素生命周期
```
spawn at x = canvas.width + 100
       ↓ scrollSpeed × dt
through screen
       ↓
when x < -150 → cleanup
```

致死障碍(divertor / instability)、软障碍(tungsten)、加成(nbi)、粒子云点(§5.6)共用同一套生命周期与滚动逻辑;
区别只在生成概率(主线 / 额外)和碰撞触发的事件类型。

### 5.6 自由电子粒子云 — 密集 +1 分流(爽感主力)

> 这是为了解决"D/T 太稀疏、玩家长时间没反馈"加入的轻量收集物。
> **它和燃料舱完全解耦** —— 只加分,不进 D/T 槽位,不触发聚变。

**视觉**:直径 8 px 的青白色小亮点(纯代码绘制,**不需要素材**),带 2 像素辉光,轻微 wobble。
**生成**:
- **不走主线 spawn**,有自己的生成器。每 0.25–0.45 秒发射一串(3–6 个),组成弧线、波浪、斜线、短直线四种 pattern 随机
- 串的起点 y 在 [80, height-80] 随机,与上一串保持 ≥ 80 px 的垂直差(避免单调)
- **避开偏滤器主体**:生成前检查接下来 200 px 内是否有 divertor 闭合区,若有则把整串 y 偏到间隙中线 ±60 px
- **进入点火高潮相后(§7.5),刷新率 ×3**

**碰撞**:
- 擦过 = +1 分 + 短促 "嗒" 视觉反馈(粒子被光球"吸入"的 0.15 秒动画)
- 不进 fuel bay,**不触发 EV.COLLECTIBLE_HIT**(避免和 D/T 系统耦合),发独立事件 `EV.PARTICLE_COLLECTED { x, y }`
- 每个粒子单独判定,**一串里可以漏吃几个**,鼓励玩家"贪心走位"

**为什么这样设计**:
- 把"持续小奖励"和"稀缺燃料"分到两条通道,**不破坏 D+T 聚变作为稀缺事件的科普叙事**
- 一串 3–6 个,玩家走位划过 = 一次性飘出 `+1 +1 +1 +1` 数字飞字 → 这就是金币串的爽感
- 串的 pattern 兼当"走位练习",**取代了我们没法做的多玩法切换**:同一操作下,粒子云让飞行轨迹有"想去摸的目标"

**科普点(轻):粒子云 ≈ 等离子体中的高能电子热辐射**;不强调,只在 modal 第 2 屏可选一句话注脚。

## 6. 收集物与聚变系统

### 6.1 氘原子(D)与氚原子(T)
**视觉**:D 蓝色发光小球(直径 16 px),内部画 1 个白点;T 绿色发光小球,内部画 2 个白点。区分度要高,色弱也能分辨(蓝 vs 绿 + 形状差异)。
**生成**:每对 Divertor 之间的间隙中,**70% 概率**飘 1 个原子,D/T 各 50% 概率。
**位置**:在间隙中心 ±40 px 随机偏移。
**碰撞**:吃到 +1 分,光球 +0.5 圈短暂高亮,记录到 `world.collectedD/T`。

### 6.2 锂-6 原子(⁶Li)— 增殖物(稀有)
**视觉**:紫银色发光原子,**辉光明显比 D/T 强**,中央叠白色 `⁶Li` 标签(贴图见 `docs/assets.md` `atom_li6.png`,96×96)。
**生成**:与 D/T 共用收集物 spawn 通道,但权重很低(10%,见 §11 `collectible.typeWeights`)。位置同 D/T。
**碰撞**:吃到立即:
- `world.collectedT += 1`(若 T 槽未满,直接增殖出 1 个 T;槽满则吃到也 +2 分但不入库)
- +2 分(比 D/T 多一倍,体现稀有)
- 飘字 `⁶Li → T 增殖`(见 `content.md` §6.2)
**设计意图**:
- **机制变化**:给 T 第二条来路,玩家追稀有物时有"赚到了"的爽感
- **科普点**:聚变堆靠 ⁶Li + n → T + ⁴He 的反应在包层(blanket)里增殖 T,因为 T 半衰期 12.3 年、自然界几乎没有,聚变堆必须自己造 — 这是工程聚变里玩家最容易忽视但最关键的物理之一

### 6.3 聚变事件
当 `collectedD ≥ 1 && collectedT ≥ 1` 时:
1. 立即触发聚变特效:
   - 光球瞬间放大 1.3×,白色闪光 0.1 秒
   - 飞出 1 个红色 He4 粒子(向左下飘) + 1 个白色中性子粒子(向右上飘),自带文字标签 "He⁴" / "n"
   - +5 分,屏幕得分数字短暂金色高亮
2. 扣除 1D + 1T(`collectedD -= 1; collectedT -= 1`)
3. `world.fusionCount += 1`

**设计目的**:让玩家意识到"我刚刚做了一次聚变反应",而不只是收集数字。HUD 应该用**视觉化燃料舱**实时显示 D / T 库存与聚变就绪状态(详见 §10.2)。

### 6.4 燃料舱库存上限
- D / T 各有上限(`config.fusion.fuelBaySlots = { D: 3, T: 3 }`),与左上角 HUD 槽位 1:1 对应
- **超过上限的 D/T 拾取仍 +1 分**(避免浪费惩罚 / 手感惩罚),但 `collectedD/T` 不再上涨
- 上限的存在让"长时间不聚变"也不会无脑积压库存,鼓励即时消耗

### 6.5 聚变 Combo — 连续聚变倍率

> 把"稀缺事件"做出"连击爽感"的关键机制。**复用现有 fusionSystem,只多一个计时器**。

**触发**:每次 `EV.FUSION_TRIGGERED` 发生时,检查上一次聚变到现在的间隔:
- 若 ≤ `comboWindow`(平时 2.0 s,高潮相 4.0 s),`comboCount += 1`
- 否则 `comboCount = 1`(重置)

**分值阶梯**(用查表而非公式,数字弹性大):

| comboCount | 本次聚变 +分 | 飘字 |
|---|---|---|
| 1 | +5(基础) | `He⁴ +5` |
| 2 | +10 | `⚡ COMBO ×2  +10` |
| 3 | +25 | `⚡⚡ COMBO ×3  +25` |
| 4 | +50 | `⚡⚡⚡ COMBO ×4  +50` |
| 5 | +100 | `⚡⚡⚡⚡ MAX COMBO  +100` |
| 6+ | +100 | (保持 MAX,不再加) |

**combo 计时器到期 / 玩家死亡 / 阶段切换都会清零**。

**视觉动感**(详细规范在 `content.md` §7.1):
- 飘字从光球位置爆出,**字号随 combo 数递增**(28 → 36 → 44 → 56 → 72 px)
- 颜色梯度:黄 → 橙 → 红 → 洋红 → 白热(`#ffcc44` → `#ff8844` → `#ff4477` → `#ff44dd` → `#ffffff`)
- 动画:0.08 秒过冲到 1.3×、回弹到 1.0×、停留 0.7 秒、向上飘 80 px 同时淡出 0.5 秒
- ×4 起,**屏幕边缘出现金色辉光脉冲一次**(代码绘制,见 `content.md` §7.2)
- ×5 起,**附带一帧白色全屏闪烁**(0.05 秒,不超过 5% 透明度,避免刺眼)
- HUD 燃料舱旁边出现 combo 计时圆环(顺时针缩,combo 窗口可视化)

**为什么这样设计**:
- 数字越大字越大、颜色越烈,**视觉本身就是反馈**,不需要看具体数字也能感到"我在叠"
- 平时 2 秒窗口约束了"必须连续触发",高潮相 4 秒窗口让连击更容易接,把高潮做成"自然 MAX COMBO 区"

### 6.6 聚变高潮窗 — 触发后的短期正反馈

> 平时也能触发的轻量机制,把"刚刚聚变"和"接下来好玩"绑在一起。**不要和 §7.4 点火高潮相混淆**:高潮窗是短时(3 秒),点火高潮相是长时(20 秒)。

聚变事件触发后,3 秒内:
- 粒子云(§5.6)刷新率 × 2
- D/T 生成概率从 70% 提升到 90%
- 屏幕轻微洋红辉光脉动(0.6 秒一周期)

**到期**:3 秒计时结束,或玩家死亡,或进入点火高潮相(§7.5,直接被升级覆盖)。

**意图**:每次聚变后给一个"再来一次"的窗口期,鼓励玩家**追着聚变打**,自然引出 §6.6 的 Combo 机制 — 因为窗口期里 D/T 更密,combo 更容易接到。

### 6.7 H 模光环(可选,二期再做)
**视觉**:金色环形,缓慢旋转。
**出现概率**:每 5% 障碍间隙生成一个,且距离上一个 ≥ 20 个障碍。
**效果**:吃到后 3 秒无敌(可穿过障碍),屏幕轻微金色调,飘字 "H-Mode 高约束模"。

> 如果几天开发时间紧,**先砍掉 H 模光环**,只做 D/T 聚变。

## 7. 难度曲线

### 7.1 温度爬升
| 通过障碍数 | 温度(百万度) | 折算 |
|---|---|---|
| 0 | 10 | 1000 万度(起步) |
| 4 | 20 | 2000 万度 |
| 16 | 50 | **5000 万度 — 太阳核心** |
| 28 | 80 | **8000 万度 — 劳森判据下限** |
| 36 | 100 | **1 亿度 — 聚变点火温度!** |
| 56 | 150 | **1.5 亿度 — 超越 ITER** |
| 76 | 200 | **2 亿度 — 突破现役纪录** |

公式:`温度(M°) = 10 + floor(obstaclesPassed / 4) × 10`

**注意**:NBI 加成通道也会推进温度档(见 §5.4),钨碎片会倒退温度档(见 §5.3)。这两个不计入 obstaclesPassed,但会让实际温度偏离上表 ±1~3 档,这是有意的张力来源。

### 7.2 滚速联动
`scrollSpeed = baseSpeed + (温度档位) × speedPerStep`

| 障碍数 | 温度档位 | 滚速 |
|---|---|---|
| 0 | 0 | 110 px/s |
| 20 | 5 | 150 px/s |
| 40 | 10 | 190 px/s |
| 80 | 20 | 270 px/s |

起步约每 3 秒过一个障碍,点火(100M°)时约 2 秒/障碍。

**为什么是这个速度(三轮校准的最终值)**:
- v0 原型(0.5s 安全窗) → 完全不可玩
- 第一轮 → drift=200 / baseSpeed=160(1.7s 安全窗,仍偏快)
- 第二轮 → 全部 ×1/3:drift=70 / baseSpeed=55(用户实测**过慢**,缺少节奏感)
- **第三轮(当前)** → 在第二轮基础上 ×2,即 v0 的 2/3:drift=140 / baseSpeed=110

目标:从画面中心到撞墙约 **2 秒**的安全窗口,飞行节奏约 **1.4 秒**一个完整起落,起步约 **3 秒**一个障碍。配合 `stepEveryNObstacles=4`,典型 60 秒一局能看到太阳核心,90 秒能摸到劳森到点火之间。

### 7.3 间距与间隙不变
障碍间距和垂直间隙保持随机区间不变。**难度提升只通过滚速来体现**——这样代码逻辑简单,玩家也容易感知"快了"。

### 7.4 温度阶段(Phase)— 操作不变,体感分相

> **本作的"多玩法感"靠这个,而不是切换控制方式**。空格永远是空格,但场景的规则、节奏、刷新率、配色都按阶段切换,玩家会感觉自己"打到了不同关卡"。

| 阶段 | 温度区间(M°) | 别名(展示给玩家) | 体感目标 |
|---|---|---|---|
| `IGNITION_PREP` | 10–30 | 等离子体启动 | 慢、稀疏、教学窗口,新手必须撑过 |
| `HEATING` | 30–80 | 主动加热 | NBI / 钨碎片登场,有奖有罚 |
| `CRITICAL` | 80–100 | 临界点 | 障碍变密,氛围紧张,等待"点火" |
| `IGNITION_BURST` | 100–150 | **点火持续期(高潮,§7.5)** | 20 秒高密度奖励窗,本作的爽点 |
| `RECORD` | 150+ | 突破纪录 | 表演时间,几乎不会到达 |

**阶段切换规则**(由 `DifficultySystem` 或新加的 `PhaseSystem` 订阅 `EV.TEMP_CHANGED`):

| 维度 | IGNITION_PREP | HEATING | CRITICAL | IGNITION_BURST | RECORD |
|---|---|---|---|---|---|
| 障碍间距倍率 | 1.0× | 1.0× | 0.9× | **0.75×** | 0.8× |
| 粒子云刷新率 | 1.0× | 1.0× | 1.5× | **3.0×** | 2.0× |
| D/T spawn 概率 | 0.7 | 0.7 | 0.7 | **0.9** | 0.7 |
| Combo 窗口 | 2.0 s | 2.0 s | 2.0 s | **4.0 s** | 2.5 s |
| 分数倍率 | 1× | 1× | 1× | **2×** | 1.5× |
| 钨碎片 spawn | off | 0.08 | 0.08 | **off** | 0.05 |
| NBI spawn | off | 0.05 | 0.05 | 0.10(双连击)| 0.05 |
| 屏幕辉光基调 | 深空蓝紫 | 洋红微脉 | 红橙微脉 | **全屏金光脉动** | 全屏白热脉动 |

**阶段切换瞬间**:
- 屏幕中部短暂飘大字阶段名(1.5 秒,见 `content.md` §8)
- 背景板辉光 / 滤色叠加在 0.5 秒内 lerp 到新基调
- 发 `EV.PHASE_CHANGED { from, to }` 事件,让所有需要响应的系统订阅

**为什么这样设计**:
- 每 20–30 秒玩家就会感到"画面变了、节奏变了、规则变了",**新鲜感不会衰减**
- 但操作完全没变(还是空格 = 脉冲),**5 秒上手原则不破**
- 阶段名直接挂温度档,**科普叙事自洽**:玩家在游戏内体感"加热阶段 → 临界点 → 点火"和真实托卡马克实验流程是同构的

### 7.5 点火高潮相(IGNITION_BURST)— 本作的爽点引擎

> 单独拎出来详细写,因为这是 MVP 的核心投入。

#### 7.5.1 进入条件
温度从 99 跨越到 100 M° 的瞬间触发,**不可重入**(同一局只触发一次,即使温度回退再上升也不重触发)。

#### 7.5.2 进入特效(0–1 秒)
- 时间轴 lerp 到 0.7×,持续 0.6 秒
- 屏幕饱和度推到极限 + 全屏金光闪烁 1 次(0.15 秒到达峰值,然后 0.5 秒回落到稳态金光叠层)
- 屏幕中央巨大飘字 `🎉 点火成功!`(72 px,见 `content.md` §8.1),0.4 秒过冲到 1.2× 再回 1.0×,停留 1.2 秒后向上飘出
- 副标题小字 `持续聚变开始 — 20 秒`,在大字下方淡入(48 px)
- **HUD 立即出现点火持续条**(见 §10.6)

#### 7.5.3 持续期(1–21 秒,共 20 秒)
- §7.4 表格中 `IGNITION_BURST` 列的所有规则全部生效
- 钨碎片**停止生成**(已存在的让它滚过去,不主动清除避免视觉跳变)
- 进度条每秒往前推 5%,玩家可以直观看到"还剩多少秒"
- 每 5 秒一个 milestone:5/10/15 秒时屏幕短暂金色脉冲一次 + 进度条"咔哒"一下放大回弹(见 `content.md` §8.3)
- **死亡仍然有效**:撞偏滤器/不稳定区照死,死亡卡片走 T5 档,但卡片副标题改为"你在点火持续期撑了 N 秒",见 `content.md` §8.4

#### 7.5.4 退出(自维持成功)
进度条满,触发 `EV.SELF_SUSTAIN_ACHIEVED`:
- 屏幕全金光爆裂 0.4 秒,**全屏粒子向外迸射**(代码生成,~200 粒,沿径向飞出)
- 中央巨大飘字 `自维持成功! +200`(96 px,见 `content.md` §8.2),持续 2 秒
- 一次性加 200 分,飘字 `+200` 与本体一起爆出
- 进入 `RECORD` 阶段(§7.4 最后一列规则生效),继续滚动直到玩家死亡

#### 7.5.5 退出(中途死亡)
- 标准死亡流程,但死亡卡片必走 T5 / T6
- 死亡卡片副标题增补"你在点火持续期撑了 N 秒"(N 由 `ignitionPhase.elapsedAtDeath` 提供)

#### 7.5.6 设计意图回顾
- 操作零切换,符合"5 秒上手"
- 把"前面 60 秒的稀缺收集"换成"20 秒的密集连击",**节奏曲线反转 = 你说的"另一种玩法的感觉"**
- 奖励集中爆发在玩家自己"加热到点火"换来的窗口,**稀缺感反过来给了高潮意义**
- 即使死了,玩家也能在死亡卡片上看到自己"点火持续了 N 秒"——离场记忆点

## 8. 得分系统

| 来源 | 分值 | 备注 |
|---|---|---|
| 通过 1 个障碍 | +1 | — |
| 吃到 1 个 D 或 T | +1 | 库满仍 +1,但不入库 |
| 吃到 1 个 ⁶Li | +2 | 自动 +1 T |
| 擦过 1 个自由电子粒子(§5.6) | +1 | 不入库,不触发 combo |
| 穿过 1 个 NBI 中性束 | 0(只加温度) | — |
| 完成 1 次聚变(基础) | +5 | combo×1 |
| 聚变 combo ×2 | +10 | 见 §6.5 表 |
| 聚变 combo ×3 | +25 | |
| 聚变 combo ×4 | +50 | |
| 聚变 combo ×5+ | +100 | MAX,封顶 |
| 自维持成功(§7.5.4) | +200 | 一次性大奖 |
| 点火高潮相内全部得分 | × 2 | 由分数倍率规则统一施加 |

**典型分数预期**(新数值下重新校准):
- 30 秒内死亡:~40 分(障碍 + 粒子云密集累加,即使没聚变也有持续反馈)
- 60 秒生存:~120 分(几次聚变 + 偶尔 ×2 combo)
- 90 秒 + 摸到点火:~250 分(进高潮相 + 几次连击)
- 撑过高潮 20 秒:~500 分(自维持 +200 + 高潮内 ×2 倍率)

得分主要用于"我比刚才更厉害了"的局间对比,**不强调排行榜**(展位不适合)。

## 10. HUD 与界面元素

固定显示在画布四角的 DOM overlay。**HUD 不每帧重绘,只在事件发生时改 DOM**(订阅 EventBus)。

### 10.1 总览

| 位置 | 元素 | 何时更新 |
|---|---|---|
| 左上 | 温度计 + 燃料舱(见 §10.2) | TEMP_CHANGED / COLLECTIBLE_HIT / FUSION_TRIGGERED |
| 右上 | 得分 + 时间 | SCORE_CHANGED / 每帧 |
| 顶部中央 | 磁场强度环(空格时亮) | INPUT_PULSE |

### 10.2 燃料舱(Fuel Bay)— 聚变机制的核心可视化

**视觉化的库存,不是数字**。这是本作 HUD 的灵魂。

```
┌─ 燃料舱 ─────────────┐
│ 🌡 5000 万度          │   ← 温度计独立一行
├──────────────────────┤
│ D  ⬤  ◯  ◯           │   ← D 槽位 ×3:亮态/暗态视觉
│ T  ⬤  ◯  ◯           │   ← T 槽位 ×3:同上
├──────────────────────┤
│ ⚡ 聚变就绪 ⚡       │   ← collectedD≥1 ∧ collectedT≥1 时显示
│ He⁴ ×3                │   ← 已聚变次数(累计成就感)
└──────────────────────┘
```

**槽位状态切换**:
- **暗态**:CSS `filter: grayscale(1) opacity(0.3)`,只用一张亮版图,不需要美术做两版
- **亮态**:无 filter,加 `box-shadow` glow(色与 atom 主色一致),收集瞬间 1.5× → 1.0× 弹性弹动

**聚变就绪指示**:
- 当 `collectedD ≥ 1 && collectedT ≥ 1` 时,立即显示 `⚡ 聚变就绪 ⚡` 行
- 金色脉冲动画(scale 1.0 ↔ 1.1,0.6s 周期)直到聚变触发

**聚变触发瞬间**(订阅 `EV.FUSION_TRIGGERED`):
- 槽位执行炸开动画:`transform: scale(1.5) rotate(15deg); opacity: 0`,0.3 秒
- 0.3 秒后槽位重新渲染为新的 D/T 数(已扣减 1 + 1)
- He⁴ 计数 +1,数字弹跳(scale 1.0 → 1.4 → 1.0)

**槽位上限**:D 3 + T 3。超出上限的拾取仍 +1 分,但库存不增(避免节奏惩罚,见 §6.4)。

### 10.3 右上 — 得分与时间
| 字段 | 模板 | 何时更新 |
|---|---|---|
| 得分 | `★ {score}` | EV.SCORE_CHANGED |
| 时间 | `⏱ {seconds} s` | 每帧(由 hud.refresh(world) 驱动) |

### 10.4 顶部中央 — 磁场强度环
圆环,空格时短暂亮一下(0.15 秒)。订阅 `EV.INPUT_PULSE`。

### 10.5 不属于 HUD
- 飘字(温度里程碑、障碍名称、Li-6 增殖、NBI 加热、钨碎片冷却、Combo、阶段切换、自维持成功)由 ParticleSystem 在 Canvas 内绘制
- 死亡卡片是独立 DOM overlay(见 §12)
- 阶段背景辉光叠层由 Renderer 绘制,**不是 HUD**(见 §13.1)

### 10.6 点火持续条(IgnitionProgressBar)— 只在 IGNITION_BURST 阶段显示

**位置**:Canvas 底部中央,距下边 24 px,宽 480 px,高 18 px。
**进入**:`EV.PHASE_CHANGED { to: IGNITION_BURST }` 时,从屏幕外向上滑入(0.3 秒缓动)。
**进度**:每秒 +5%(20 秒走满)。逐帧线性,不跳变。
**视觉**:
- 底层:深空蓝紫圆角矩形(`#0a0e27`),边框 2 px 金色 `#ffcc44`
- 填充:洋红 → 金的水平渐变,前进时**头部一段拉出 8 px 高光带**(像热铁条)
- 每 5 秒里程碑(5/10/15 s)时:进度条整体 scale 1.08 → 1.0(0.25 秒弹性),金光闪一下
- 满条:进度条本体爆裂消失,触发 §7.5.4 自维持特效
**事件订阅**:`EV.PHASE_CHANGED`(进入/退出)、`EV.IGNITION_TICK`(可选,逐帧也行)、`EV.SELF_SUSTAIN_ACHIEVED`(炸开)。
**文字**:进度条上方居中小字 `点火持续 {elapsed} / 20 s`(等宽字体,18 px,见 `content.md` §8.5)。

### 10.7 Combo 计时圆环 — 紧邻燃料舱

**位置**:燃料舱模块右侧,直径 36 px。
**显示条件**:`comboCount ≥ 2` 时出现,combo 重置时消失(0.2 秒淡出)。
**视觉**:
- 圆环外圈:当前 combo 数对应颜色(同 §6.5 颜色梯度)
- 圆环填充比例 = `remainingTime / comboWindow`,**顺时针缩短**(像倒计时表盘)
- 圆心数字:当前 combo 数(等宽,16 px,白色描边)
- 每次成功接到一次新 combo:整环 scale 1.4 → 1.0 弹性回弹,并切到下一档颜色
- 还剩 0.4 秒时:**圆环开始红色闪烁**(0.1 秒周期),提醒"快接下一发"

### 13.1 背景板与阶段辉光层 — 沉浸感来源

> **核心约束**:用户只提供 2D 静态素材(背景板 PNG)。**所有光晕、辉光、脉动、滤色、扫线等动态特效全部由代码运行时绘制**。这条约定必须严格遵守,以便美术不用反复出图。

**渲染顺序(从底到上)**:
```
1. background_tokamak.png       ← 用户提供的静态背景板(托卡马克环视角)
2. 阶段辉光叠层                  ← 代码绘制,radialGradient,色相按 phase.glow 变
3. 视差网格 / 远景磁力线         ← 代码绘制,慢速向左滚动
4. 场景元素(障碍 / 收集物 / 粒子云 / Boost)
5. 等离子体光球 + 拖尾           ← Canvas 几何 + 渐变
6. 前景粒子特效(聚变、Combo 飘字、自维持迸射)
7. HUD / 进度条(DOM 或 Canvas overlay)
```

**阶段辉光层**(纯代码,无素材):
- 一个**全屏 radialGradient**,中心在画布中央,边缘羽化到透明
- 颜色按 §7.4 表的 `glow` 字段映射(`deep` / `magenta` / `redOrange` / `gold` / `whiteHot`),阶段切换时 0.5 秒 lerp
- 透明度按 phase 不同(`deep` 5% → `gold` 25%),且**叠加 0.6 Hz 的低频呼吸脉动**(amplitude ±20%)
- 高潮相(`gold`)额外叠加屏幕边缘的金色框形辉光(`vignette` 风格,内透外不透)

**背景板内容要求**(规格细节在 `docs/assets.md`):
- 必须是**从托卡马克环内部往外看的视角**(玩家像站在 D 形真空室里),环壁、偏滤器板、诊断窗、磁体线圈隐约可见
- **不能太亮太抢戏**(它是背景,不能盖过等离子体光球)
- **不能带动画 / 不能闪烁** — 那些都靠代码叠层补

视差与远景磁力线也是代码绘制,**不要素材化**。
