> 本文档是**所有玩家可见文字的唯一权威来源**(架构文档 §3.4 DRY 的"叶子"之一)。
> `src/content.js` 必须从本文档同步;反向也成立——文案要改,先改本文档,再同步到代码。
> 配套文档:`architecture.md`(代码组织) / `game-design.md`(玩法与数值)。

## 1. 文案总则

### 1.1 受众与语气
- **受众**:开放日参观者中小学生 + 家长占多数,高中/大学生其次,偶尔同行学者
- **基调**:**热情 + 准确,不卖弄**。能用一句讲清的不写两句
- **避免**:行话堆砌("等离子体动力学不稳定性中的 m=1 模式撕裂特征…")、空泛感叹("好厉害啊!")、说教("你应该知道…")

### 1.2 排版规则
| 规则 | 例 |
|---|---|
| 数字与中文之间留空格 | `47 秒`、`5000 万度`、`完成 3 次聚变` |
| 数字与拉丁文/单位之间留空格 | `13 T`、`400 s`、`ITER` 前后视情况 |
| 标点用全角 | `,。!?:;""''` |
| 大数用万 / 亿,不用百万 / 十亿 | ✅`1 亿度` ❌`100 百万度` |
| 表情符号克制使用 | 仅 HUD 标志(🌡 ⏱ ★)、死亡标题(💥)、聚变特效 |

### 1.3 占位符约定
代码渲染时需要替换:
- `{seconds}` — 本局生存秒数(整数)
- `{temperature}` — 达到的最高温度,人类可读格式("8000 万度" / "1.2 亿度")
- `{fusionCount}` — 完成的聚变次数
- `{score}` — 最终得分

格式化函数 `formatTemperature(M°)` 的实现规范:
- `< 100` → `{n*10} 万度`(如 30 → "3000 万度")
- `≥ 100` → `{n/100} 亿度`,保留 1 位小数,小数为 0 时省略(如 100 → "1 亿度",150 → "1.5 亿度")

## 4. HUD 文案与格式

HUD 是 DOM,**视觉化优先**(完整 HUD 设计见 `game-design.md` §10)。本节只列文字模板。

### 4.1 数字字段(模板)
| 字段 | 模板 | 示例 |
|---|---|---|
| 温度 | `🌡 {temperature}` | `🌡 5000 万度` |
| 得分 | `★ {score}` | `★ 47` |
| 时间 | `⏱ {seconds} s` | `⏱ 32 s` |
| He⁴ 累计 | `He⁴ ×{fusionCount}` | `He⁴ ×3` |

### 4.2 燃料舱(左上,视觉化无文字)
**库存由槽位图标视觉表达,不显示数字**(D 和 T 各 3 个槽位)。文字仅有以下两段:

| Key | 文案 | 触发条件 |
|---|---|---|
| `hud.fuelBay.label` | `燃料舱`(可选,做不做都行) | 一直显示 |
| `hud.fuelBay.fusionReady` | `⚡ 聚变就绪 ⚡` | `collectedD ≥ 1 && collectedT ≥ 1`,聚变触发后立即清除 |

槽位的暗 / 亮态、聚变就绪的金色脉冲、He⁴ 弹跳计数都由 CSS 动画 + 事件订阅驱动,不需要文字模板。

HUD 不显示障碍数 / collectedD / collectedT 数字(那是内部指标,玩家不应该看到原始数字)。

## 5. 温度里程碑飘字(Canvas 内浮动文字)

由 `TemperatureSystem` 在跨越阈值时发出 `EV.TEMP_MILESTONE`,ParticleSystem 渲染。
**显示位置**:屏幕中部偏上。**显示时间**:1.5 秒淡入淡出。

| 阈值(M°) | 文案 | 备注 |
|---|---|---|
| 50 | 已超过太阳核心温度 | 太阳核心 ≈ 1500 万度,这里夸张到 5000 万好玩家容易够到 |
| 80 | 接近劳森判据下限 | 劳森判据是工程聚变可行性指标 |
| 100 | 达到聚变点火温度! | **配合金色闪光特效**,本作高潮时刻 |
| 150 | 超越 ITER 设计参数 | ITER 目标约 1.5 亿度 |
| 200 | 已突破现役实验最高纪录 | 现役托卡马克瞬时温度纪录约此区间 |

> **设计意图**:让"太阳核心"和"劳森"这两个名词在玩家头脑里和"游戏中我达到的某个具体温度"绑定。看完游戏一周后还能想起来"哦,5000 万度好像是太阳核心",就成功了。

## 6. 场景元素飘字与拾取反馈

由 ParticleSystem 在 Canvas 内浮现。位置:**屏幕中部偏上**,**显示时间 0.6–0.8 秒淡出**(里程碑除外,见 §5)。

### 6.1 MHD 不稳定区(InstabilityRegion)生成时
障碍名称三选一随机(0.8 秒淡出):

| 名称 | 现实物理对应 |
|---|---|
| 撕裂模 | Tearing mode,磁岛形成 |
| 气球模 | Ballooning mode,曲率驱动 |
| 锯齿模 | Sawtooth oscillation,芯部反演 |

普通参观者读到名字就当作"哦原来这种叫撕裂模",同行看到会会心一笑。

偏滤器(Divertor)**不显示飘字**,作为"水管"是默认障碍,频繁飘字反而干扰玩感。

### 6.2 锂-6(⁶Li)拾取
拾取瞬间屏幕中部飘字(0.6 秒淡出,紫银色):
```
⁶Li → T 增殖
+2
```
**意图**:让玩家明白"刚才那个紫的不是普通氚,是通过锂增殖出来的"。一次飘字承担科普 + 计分两个反馈。

### 6.3 钨碎片(TungstenDebris)撞击
撞击瞬间屏幕中部飘字(0.6 秒淡出,冷灰白色):
```
钨杂质溅射
等离子体冷却 −1 档
```
配合屏幕 0.3 秒红闪 + 等离子体短暂闪烁。
**注意**:钨碎片**不致死**,飘字语气是"被冷却"而不是"实验中断",玩家应能感受到"还能玩,只是退步"。

### 6.4 NBI 中性束(NeutralBeamInjection)穿过
等离子体接触加成带瞬间飘字(0.6 秒淡出,洋红 → 金色渐变):
```
中性束加热!
+1 档
```
配合等离子体 0.5 秒金光高亮 + 通道淡出。

### 6.5 配色对照
| 飘字 | 主色 | 用意 |
|---|---|---|
| 不稳定区名称 | 红橙 #ff5544 | 警告/危险 |
| Li-6 增殖 | 紫银 #cc88ff | 稀有/赚到 |
| 钨碎片 | 冷灰白 #ccd0d8 | 工业事故感 |
| NBI 加热 | 洋红 → 金 渐变 | 能量奖励 |
| 温度里程碑(§5) | 各档独立色 | 与里程碑色一致 |

## 8. 死亡卡片(主科普位)

死亡 0.6 秒后淡入。结构:

```
┌─────────────────────────────────────────────┐
│             💥 {死因标题}                    │
│                                             │
│   你坚持了 {seconds} 秒,                    │
│   达到了 {temperature}                       │
│   完成 {fusionCount} 次聚变反应              │
│                                             │
│ ─────────────────────────────────────────── │
│                                             │
│   {tier_body}                               │
│                                             │
│        [ 按空格 再来一次 ]                   │
│        [ 了解更多 ↗ ]                        │
└─────────────────────────────────────────────┘
```

### 8.1 死因标题(根据死亡类型)

| 死因 | 标题 |
|---|---|
| 撞上下炉壁 | 等离子体接触炉壁 |
| 撞偏滤器 | 偏滤器板汽化 |
| 撞不稳定区 | MHD 不稳定性失控 |

### 8.2 科普段落(根据本局达到的最高温度)

> 实现规范:`getDeathBody(maxTemp)` 返回对应文案。**取严格小于的最大档位**(例如 maxTemp=100 走 T5 而非 T4)。

**T1 — `maxTemp < 30`(典型 0–10 秒就死)**
```
等离子体非常脆弱——哪怕是最初的 1000 万度,
也已经把任何固体材料瞬间汽化。
这就是为什么我们需要磁场把它"悬空"住,
让它一刻都不接触炉壁。
```

**T2 — `30 ≤ maxTemp < 50`**
```
不错的开局!你已经把等离子体加热到了 {temperature}。
作为参考:太阳核心约 1500 万度,
你已经远远超过它了——只是比起聚变反应需要的温度
还差一些。
```

**T3 — `50 ≤ maxTemp < 80`**
```
{temperature} —— 你已经超过太阳核心了。
但要让氘氚发生足够多的聚变反应,
人类需要的是太阳核心 5–10 倍的温度。
原因很简单:地球上没有太阳那样的引力压力,
我们只能靠"更高温度"来弥补。
```

**T4 — `80 ≤ maxTemp < 100`**
```
{temperature} —— 你触到了"劳森判据"的门口。
这是工程上判断聚变能否净产能的指标:
温度、密度、约束时间三者乘积要够大。
你已经搞定了温度,真实的 ITER 还得搞定后两个。
```

**T5 — `100 ≤ maxTemp < 150`(高潮档位)**
```
🎉 {temperature} —— 你点火了!

聚变点火温度是 1 亿度。这是地球上人为创造的
最极端环境之一。
你坚持了 {seconds} 秒、完成了 {fusionCount} 次聚变。
现实中 ITER 的目标是稳定维持 400 秒以上。
```

**T6 — `maxTemp ≥ 150`**
```
{temperature} —— 已经超越 ITER 的设计参数了。
你大概是研究室的人,或者天赋异禀。
我们办公室在 3 楼,欢迎来聊。
```

### 8.3 通用 ITER 对照(放在 T1–T4 卡片底部小字)

```
ITER 用 13 T 的超导磁场约束 1.5 亿度等离子体,
目标维持 400 秒以上的聚变反应。
```

T5 / T6 不重复这段(主体已经讲过)。

## 9. "了解更多" Modal 内容

点击死亡卡片"了解更多"按钮后弹出。三屏:

### 9.1 第 1 屏 — 能量密度对比

```
为什么我们要做聚变?

    1 g 氘氚燃料  ≈  8 吨石油  ≈  11 吨煤

  几乎不产生温室气体,
  原料从海水里就能提取。
```

配图:左边一个小试管(1g),右边一辆油罐车 / 一堆煤,视觉强反差。
图可由 Canvas 直接画,也可用预制 PNG。

### 9.2 第 2 屏 — 难在哪

```
难点不是"加热到 1 亿度",
而是"让 1 亿度的东西不接触任何容器"。

任何固体一接触就立刻汽化、污染等离子体。
唯一可行的办法:用强磁场"悬浮"住它。

ITER 的超导磁体重 1 万吨,
能产生 13 T 的磁场——是地球磁场的 26 万倍。
```

### 9.3 第 3 屏 — 我们在做什么

```
{研究室一句话简介,待你补充}

[研究室二维码]      [实验室主页]

谢谢来玩!
```

> ⚠️ **第 3 屏需要研究室提供**:一句话定位、二维码图片、主页 URL。这块留空,等你给我素材。

## 10. 彩蛋

| 触发条件 | 文案 / 表现 |
|---|---|
| 单局聚变次数 ≥ 10 | 飘字 `氘氚收割机` |
| 距离炉壁 < 10 px 累计 5 秒还活着 | 飘字 `贴墙艺术家` |
| Konami code(可选,二期) | — |

彩蛋的目的是给"重玩动机"。普通玩家玩两次就走,不会触发;玩四五次的玩家会发现新东西。

## 12. 文案版本管理

- 改文案 = 改本文档 + 改 `src/content.js`,**两处必须同步**
- `content.js` 的 key 命名遵循 `区域.子项`(如 `ui.title`、`death.body.t5`)
